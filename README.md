# 念念 AI 复利知识库

> AI 视频、短剧、漫剧、自动化与项目实践的可复用知识资产库。

## 目标

把工具、软件、网站、FastAPI 服务、Playwright 自动化、GitHub 开源项目、B 站信息差、念念系列项目和 Skill 工作流，整理成：

- 看得懂的知识卡片
- 团队可复用的 SOP
- Codex / WorkBuddy 可执行的 Skill 与 Prompt
- 可发布到 GitHub 的一键使用包
- 面向公开用户、团队成员、私域用户的分层内容

## 权威项目定义

- 权威文档：`E:/codex/niannianai/niannianai/authority/COMPOUNDING_KNOWLEDGE_AUTHORITY.md`
- 原则：知识卡是最小单位，文档是详情页；按用户意图组织；支持公开、团队、私域三层分发。

## 当前版本

- 版本：`0.1.0-mvp`
- 状态：骨架已建立，首批资产待持续填充
- 主线：AI 视频 / 短剧 / 漫剧生产
- 维护方式：内容卡片 + 元数据 + 可视化门户 + 更新日志

## 目录

- `docs/workflows/`：可执行工作流
- `docs/tools/`：工具与软件卡片
- `docs/projects/`：念念系列项目卡片
- `docs/automation/`：FastAPI、Playwright、批处理和部署资产
- `metadata/`：统一索引和标签
- `dashboard/`：静态可视化门户

## 内容状态

`draft` 草稿 · `review` 待验证 · `verified` 已验证 · `recommended` 推荐 · `stale` 待更新 · `deprecated` 已废弃

## 分发层级

- `public`：公开展示和入门内容
- `team`：团队协作与生产内容
- `private`：私域付费和高级资产

## 首批资产来源

当前工作区已经存在念念 AI、念念智选、念念提分、念念智剪、豆包视频服务等项目，后续按统一卡片规范整理，不直接复制发布构建产物。

## 贡献规则

每条新增知识必须补充：来源、适用场景、输入输出、验证状态、版本、更新时间、维护人和分发层级。未经验证的外部工具不得标记为 `verified`。
