# 知识卡入库检查清单

## 采集信息

- [ ] 标题与原始链接 / 本地路径
- [ ] 来源类型
- [ ] 访问和版权边界
- [ ] 作者、仓库、发布或更新时间
- [ ] 关键结论或关键时间点
- [ ] 关联的项目、工具、工作流

## 判断信息

- [ ] 解决的具体问题
- [ ] 目标人群
- [ ] 输入、处理、输出
- [ ] 前置条件、授权、成本
- [ ] 可复制性与结果确定性
- [ ] 复利评分 1～5
- [ ] public / team / private 分发层

## 入库安全

- [ ] 不包含密钥、Cookie、账号、签名 URL、用户数据
- [ ] 外部资料默认 review
- [ ] 未实测方案默认 draft
- [ ] 一键动作只指向真实、授权、可复现的入口
- [ ] 详情页与 metadata 索引一致

## 交付前

- [ ] `npm run validate` 通过
- [ ] 门户中可搜索、筛选和打开详情
- [ ] CHANGELOG 记录用户可感知更新
- [ ] 未经明确授权，不提交、不推送、不公开
